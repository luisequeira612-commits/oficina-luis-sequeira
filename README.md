# Oficina de Luis Sequeira

Panel estático de simulación para visualizar personajes de trabajo agrupados por proyecto.

## Uso

Abre `index.html` en un navegador o publica el repositorio con GitHub Pages. La Fase A es una simulación local: no se conecta a GitHub ni a servicios externos.

- Añade proyectos y personajes, y elimina los que ya no necesites.
- Los proyectos y roles se guardan en el almacenamiento local del navegador.
- Los estados de actividad cambian aleatoriamente y no se guardan.
- La información permanece en el dispositivo y navegador donde se creó.

## Tecnología

HTML, CSS y JavaScript sin dependencias, backend, cuentas, API ni claves. No incluye service worker ni manifiesto.

## Alcance

Fase A: simulación visual. Una futura fase podrá conectar estados reales de repositorios públicos, sin cambiar el carácter estático de esta primera entrega.
